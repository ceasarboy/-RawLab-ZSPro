# 验证② 记录：参照对拟合 3D LUT 方法对比实验

日期：2026-10-03。脚本：`verify_lattice_fit.py`（同目录）。环境：Python 3.13.5 / numpy 2.4.5 / scipy 1.18.0 / colour-science 0.4.7。

## 实验设计

- **真值**：解析风格变换 T = 3×3 通道混合 ∘ 逐通道 gamma + 黑位抬升（光滑、单调、点态，即合法 3D LUT 对象），模拟"中性渲染 vs 目标风格"参照对。
- **训练**：12³ 网格 + 8000 随机点（共 9728 对）；**验证集** 3000 点（选 λ）；**测试**：20000 随机点 + ColorChecker 24（BabelColor Average 实测值）+ 中性灰阶带（单调性/平滑性）+ 蓝色 hue ramp（翻车点 #1）。
- **方法**：A 3×3+偏置最小二乘；B1 普通 20 项 deg-3 多项式（Vandermonde 型，自实现）；B2 colour-science 官方 **Finlayson 2015 根多项式**；C 17³ lattice 回归 + 二阶差分平滑正则（Gupta CIC2009 型，自实现，稀疏正规方程求解）。
- 指标：ΔE00（sRGB→XYZ→Lab/D50），中性带单调性违例数、最大二阶差分（banding 代理）。

## 结果

| 方法 | 随机20k meanΔE00 | maxΔE00 | 色卡24 meanΔE00 | 单调违例 | max 2nd-diff |
|---|---|---|---|---|---|
| ground truth | 0 | 0 | 0 | 0 | 0.0009 |
| A 3×3+offset | 0.7972 | 6.146 | 1.1300 | 0 | 0.0008 |
| C lattice(17³) λ=0 | **0.0339** | 2.953 | **0.0224** | **34** | 0.0035 |
| B1 poly-deg3(20项) | 0.0792 | **0.726** | 0.1072 | 0 | 0.0000 |
| B2 Finlayson2015根多项式 | 4.4081 | 26.03 | 6.7533 | 0 | 0.0000 |

λ 扫描（验证集 meanΔE00）：λ=0 → 0.035；1e-4 → 0.617；1e-3 → 4.23；1e-2 → 20.35；1e-1 → 37.90。

## 结论（对 04 报告的实验确认与补充）

1. **lattice 回归精度最优**（随机/色卡 mean ΔE00 = 0.034/0.022），但 **λ=0（无约束）在中性带上产生 34 处单调性违例**——ΔE 均值完全看不见它，只有灰阶带检查能抓住。这实验性确认了 04 报告的核心论断：**生产拟合器必须带单调性/平滑约束，ΔE 均值指标必须配 ramp 检查**。
2. **根多项式（Finlayson 2015）不适用于胶片风格拟合**：它的基无常数项、齐次（f(cx)=c·f(x)），**不能表达黑位抬升/亮度偏移**——而"褪色黑位"恰是大多数胶片风格的特征。它的正确用途是保中性的标定类变换（相机特征化）。这修正了 04 报告把 Finlayson 2015 列为通用快速基线的表述：**通用基线应是普通多项式 deg-3，根多项式仅用于保中性场景**。
3. 普通 deg-3 多项式在光滑目标上表现出乎意料地好（本实验目标恰为多项式友好型；真实胶片风格曲率更高，优势会缩小），maxΔE00=0.726 与全程平滑/单调——作为拟合初始化与交叉验证基线合格。
4. λ 选择敏感（1e-4 已开始劣化）：本实验的尺度归一化方式与真实数据（稀疏、含噪、非均匀覆盖）不符，**生产 `fit-lut` 的正则项设计需在真实参照对上重新标定**，并优先考虑 TF Lattice 式的不等式（单调）约束而非纯二次平滑。
5. 自实现的机制件（三线性权重稀疏矩阵、K³ 二阶差分算子、稀疏正规方程求解、ΔE00 分桶评估）全部可复用为 `lutools fit-lut` 的原型内核。

## 复现

```sh
python verify_lattice_fit.py
```

注意：B2 使用 colour-science 官方 API（`matrix_colour_correction` + `colour_correction`，method='Finlayson 2015'）；该实现的基为根多项式，与自实现的普通 20 项多项式不是同一方法——04 报告原文的"Finlayson 2015（向量多项式）"表述易误导，已在此勘误。
