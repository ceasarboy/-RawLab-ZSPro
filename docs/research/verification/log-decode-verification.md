## 过程中发现并修正的问题（对 01 报告的勘误/补充）

1. **V-Log 解码分支点是 y=0.181，不是趾部起点 0.125**。官方 toe 段 `y=5.6x+0.125` 覆盖 y∈[0.125, 0.181]（x∈[0, 0.01]），解码时 y<0.181 全部走 `(y-0.125)/5.6`。colour-science `CONSTANTS_VLOG cut2=0.181` 证实。若按"y<0.125 才走趾部"实现，CV 128–185 区间会产生最大 ~2e-3 的反射率误差（黑位附近可见台阶）。
2. **S-Log3 趾部分支点为 CV 171.2102946929**（x=0.01125 的编码值），CV 95 以下线性延伸承载负值。colour-science `sony.py` 实现与白皮书一致。
3. **F-Log2 与 F-Log 是两条不同曲线**（@CV400 解码分别为 0.180 与 0.108），管线必须分别实现；colour-science 0.4.7 只有 F-Log，F-Log2 按富士 Data Sheet Ver.1.0 公式自实现并通过锚点核对。
4. 厂商数据表的"码值百分比"有两种口径：Sony 的 4%/41%/61% 是 **legal range（64–940）** 上的百分比，对应的 full-range 码值即 95/420/598。文档化时必须写明口径，否则会复现出 41/410/624 这类错误曲线。
