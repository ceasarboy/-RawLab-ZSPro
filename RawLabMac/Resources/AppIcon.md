# RawLab App Icon

Created with the built-in image generation tool on 2026-09-27. The user rejected
the initial dimensional camera/film concept and requested an abstract, simple,
flat design. Only the revised artwork is shipped. It contains no Fujifilm or
Apple branding. Transparent PNG master; native `sips` resizing and `iconutil`
packaging produce the macOS icon family without changing the design.

## Generation Prompt

Redesign this rejected RawLab macOS icon radically. The user wants MUCH more abstract, simple and flat. Discard ALL photographic aperture blades, film perforations, camera/lens imagery, bevels, glossy surfaces, shadows, gradients, material texture and 3D. Create a refined flat graphic app icon on a true transparent 1024 square canvas, with a neutral almost-black #232323 macOS rounded-square tile centered with 8% transparent margin. The ONLY symbol on the tile is a precise, bold geometric mark made of TWO overlapping, offset rectangular photographic frames: an upper-left warm yellow #F7CE46 open frame and a lower-right clean cyan #55CED4 open frame. Both frames have exactly the same square-ish 5:4 proportions and thick consistent strokes, crisp square inner corners with only subtly softened outer joins. Their overlap uses a single small light neutral white intersection, conveying exposure and color-space transformation. This should look like a carefully designed modernist photo-tool brand mark, not an illustration, no camera, no circle, no rainbow. Use only charcoal, yellow, cyan and the tiny neutral intersection. Central symbol takes about 56% of the icon width with generous breathing space. Strictly front-facing, no perspective, no tilt. Completely flat, uniform solid color regions with NO lighting at all. No letters, text, gradients, decorative lines or watermark. One finished standalone icon, not a presentation sheet.
